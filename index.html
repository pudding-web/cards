Flashcard Review

Hover a card to reveal the answer.

1) What does CSS stand for?

Cascading Style Sheets

2) What tag links an external CSS file?

<link rel="stylesheet" href="styles.css">

3) What does :hover do?

Applies styles when the mouse is over an element

4) What property changes text color?

color

5) What property changes background color?

background-color

6) What does padding do?

Adds space inside an element (between content and border)

7) What does margin do?

Adds space outside an element (between elements)

8) What does transition do?

Smoothly animates a change between styles
